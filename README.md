# 🌦️ Weather App - Dynamic Theme & UI

A modern, responsive, and visually dynamic Flutter application that provides real-time weather information for cities worldwide. The app dynamically adapts its background gradients, themes, and UI assets based on the current weather conditions.

---

## ✨ Features

- 🌍 **Global Weather Search:** Search and get real-time weather details for any city.
- 🎨 **Dynamic Theming:** App color scheme and background gradients automatically adapt to weather states (e.g., Sunny, Rainy, Snowy, Thunderstorm).
- 🖼️ **Custom Weather Assets:** High-quality custom icons for various weather conditions instead of default API icons.
- 🔄 **State Management:** Clean and structured state management using **Flutter Bloc (Cubit)**.
- ⚡ **REST API Integration:** Fetches accurate weather data using [WeatherAPI](https://www.weatherapi.com/) via `Dio`.
